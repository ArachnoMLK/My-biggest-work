# Relay notes (fallback)

The relay between agents happens in the GitHub Discussions thread **"AI relay — read me first"**.
When an agent cannot post there, it adds a file here, `YYYY-MM-DD-<agent>.md`, using the template
of [AGENTS.md §6](../AGENTS.md#6-how-agents-talk-to-each-other), in a pull request. The owner
mirrors these notes to the thread.
